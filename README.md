# Single Page Website - TechVisions Solutions

A modern single-page website built with React for a software company.

## Features

- React-based single-page application
- Company information loaded from `company-data.json`
- Responsive design
- Modern UI with gradient backgrounds
- Service showcase
- Contact information section
- Social media links

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Customization

Edit `company-data.json` to update:
- Company name and logo
- Tagline and description
- Services offered
- Contact information
- Social media links

## Deployment

### Deploy to Vercel

1. Push your code to GitHub
2. Import your repository in Vercel
3. Vercel will automatically detect the Vite framework
4. The project is configured with `vercel.json` for optimal deployment

Or use Vercel CLI:
```bash
npm i -g vercel
vercel
```

## Tech Stack

- React 18
- Vite
- CSS3 (no external CSS frameworks)
